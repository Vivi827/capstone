# Pally 명시적 대화 목적 중간 표현 기반 응답 생성 최종 실험설계서

중의적·비격식 사용자 발화에서 명시적 대화 목적 표현이 의미 보존과 후속 대화 연속성에 미치는 효과를 검증하는 파일럿 연구

- 문서 상태: 학부생 ACK 논문 경진대회용 최종 연구계획
- 기준 Rubric: Pally 측정 Rubric v2.2
- 대상 축: Formality · Humor · Curiosity
- 표본 규모: 100개 항목
- 자료 분할: 학습 80개 · 최종 실험 20개
- 예측 방법: 단순 기계학습
- 주 평가자: 연구자 4인
- 기준일: 2026-09-22

## 연구 설계 요약

본 연구는 중의적·비격식 표현이 포함된 사용자 발화에서 대화 목적을 명시적 중간 표현으로 추가하는 것이 최종 응답의 적합성과 후속 대화 연속성에 주는 증분 효과를 검증한다. Direct 조건과 Purpose-aware 조건은 동일한 Formality·Humor·Curiosity 예측값을 공유한다. Purpose-aware 조건만 대화 목적을 추가로 예측하여 응답 생성기에 제공한다. 따라서 두 조건의 응답 차이는 명시적 대화 목적 표현의 추가 여부로 해석한다.

본 연구에서 슬랭의 의미 이해는 단어의 문자적·비문자적 뜻을 맞히는 데 그치지 않는다. 모델이 해당 표현의 의미, 화자의 태도, 현재 발화가 요구하는 반응을 보존하고, 같은 의미 맥락에서 다음 대화를 자연스럽게 이어갈 수 있는 응답을 생성했는지를 함께 평가한다.

분석 단위는 최소한의 이전 문맥과 현재 사용자 턴으로 구성된 하나의 항목이다. 각 항목에는 모델에 제공되지 않는 평가용 후속 대화 기준을 함께 작성한다. 두 조건은 동일한 입력 문맥, 세 축 예측값, 데이터 분할, 응답 생성기, 길이 제한 및 생성 설정을 사용한다. 조건 간 핵심 차이는 예측된 대화 목적을 응답 생성기에 명시적으로 제공하는지 여부이다.

주 결과는 연구자 4인이 블라인드로 평가한 A/B 응답의 쌍대 결과와 좋은 응답 통과율이다. 중대한 의미 오해율과 대화 연속성 점수는 핵심 결과로 함께 보고한다. 목적 macro-F1, 축별 MAE·Spearman 상관, 목적 오류에서 응답 오류로 이어지는 전파 구조는 과정 및 진단 지표로 사용한다.

| 구분 | 확정 설계 |
|---|---|
| 분석 단위 | 최소 이전 문맥 0–1턴 + 현재 사용자 턴 + 모델 응답 |
| 조건 A | 문맥·사용자 턴 → 3축 예측 → 응답 |
| 조건 B | 문맥·사용자 턴 → 동일한 3축 예측 + 대화 목적 예측 → 목적·3축 조건부 응답 |
| 표본 | 총 100개 중 학습 80개, 최종 실험 20개. lexical family 단위 분리 |
| 주 평가자 | 연구자 4인, 독립·블라인드 평가 |
| 주 결과 | A/B 승패·동률·둘 다 부적합·판정 불일치 및 좋은 응답 통과율 |
| 핵심 결과 | 중대한 의미 오해율, 대화 연속성 점수 |
| 과정 지표 | 목적 macro-F1, 공통 축 모델의 MAE·Spearman, 목적 정·오분류별 응답 오류 |
| 범위 | Energy·Intimacy 제외, v1.0·pseudo-label 제외, v2.2 human final label 사용 |

### 연구 질문의 한 문장 버전

> 동일한 사용자 발화와 동일한 세 축 예측을 사용하는 조건에서, 예측된 대화 목적을 명시적 intermediate representation으로 응답 생성기에 추가하면 중의적·비격식 표현의 의미와 화자의 태도를 보존하면서 후속 대화로 자연스럽게 이어지는 응답이 증가하는가?

## 1 연구 배경과 문제 정의

Pally의 목표는 사용자 발화에서 관찰되는 스타일을 측정하고 그 결과를 응답 생성에 활용하는 것이다. 그러나 기존 weak label과 pseudo-label은 인간이 지각한 스타일을 보장하지 않으며, `human_spoken=true` 역시 입력을 인간이 말했다는 출처 표지일 뿐 human label을 뜻하지 않는다. 따라서 본 실험은 새로 작성한 인간 라벨을 기준으로 하며, 기존 v1.0과 rule 또는 LLM pseudo-label을 주 분석의 학습 정답에서 제외한다.

중의적 슬랭과 비격식 표현은 표면 단어만으로 의미를 확정하기 어렵다. `ate`는 음식 섭취를 뜻할 수도 있고 뛰어난 수행에 대한 칭찬을 뜻할 수도 있다. `dead`, `sick`, `cooked` 역시 문맥과 화자의 태도에 따라 서로 다른 의미와 대화 기능을 가진다. 따라서 슬랭 이해는 토큰의 뜻을 선택하는 과제가 아니라, 현재 발화가 상대에게 어떤 반응을 요구하는지 판단하고 그 해석을 후속 응답에 유지하는 과제로 볼 필요가 있다.

대화 목적은 발화가 상대에게 요구하는 반응을 요약하는 중간 표현이다. 본 연구는 대화 목적을 Pally에 맞춘 6개 범주로 조작화하고, 동일한 발화와 동일한 세 축 예측에 목적 표현을 추가했을 때 의미 오해와 대화 단절이 줄어드는지 검증한다. 목적 분류기 자체의 새로움이나 분류 성능을 주된 contribution으로 주장하지 않는다.

### 1.1 연구 공백

선행연구는 대화행위 분류, 속어 탐지·해석, 스타일 측정, 자동 생성 평가를 각각 다루어 왔다. 그러나 명시적 대화 목적 표현이 중의적·비격식 발화에 대한 응답 생성에서 다음 세 단계에 어떤 차이를 만드는지는 별도로 검증할 필요가 있다.

1. 슬랭의 문자적·비문자적 의미와 화자의 태도를 올바르게 해석하는가.
2. 해당 발화가 요구하는 반응 유형을 수행하는가.
3. 그 해석을 유지하면서 다음 대화가 이어질 수 있는 구체적인 연결을 제공하는가.

본 연구는 새로운 대규모 모델 구조의 제안보다, 명시적 의사소통 기능 표현의 증분 효과와 오류 전파 경로를 통제된 조건에서 검증하는 데 초점을 둔다.

### 1.2 범위와 용어

- **대화 목적**은 장기적인 사용자 목표가 아니라 현재 사용자 턴이 상대에게 주로 요구하는 반응의 종류이다.
- **중의적 표현 개선**은 단어 하나의 뜻을 맞히는 것이 아니라, 표현을 포함한 발화 전체의 의미와 화자 태도가 응답에서 보존되는 것을 뜻한다.
- **대화 연속성**은 실제 사용자가 더 오래 대화했다는 뜻이 아니다. 현재 응답이 동일한 의미 맥락의 후속 사용자 턴과 자연스럽게 연결될 수 있는지를 뜻한다.
- **좋은 응답**은 의미 보존, 목적 충족, 스타일 조절, 대화 연속성, 자연스러움 기준을 충족하고 중대한 의미 오류가 없는 응답이다.
- **단서 shortcut 사례**는 특정 단어나 기호만 보고 모델이 의미, 목적 또는 스타일을 성급하게 단정하는 사례이다.

## 2 연구 목적 질문 및 가설

### 2.1 연구 목적

명시적 대화 목적을 intermediate representation으로 추가하는 것이 최종 응답의 의미 보존, 목적 충족, 스타일 적절성 및 대화 연속성에 주는 증분 효과를 검증한다. 또한 목적 분류의 성공과 실패가 최종 응답 오류에 어떻게 연결되는지 분석한다.

### 2.2 연구 질문

| ID | 연구 질문 |
|---|---|
| RQ1 | Purpose-aware 조건 B는 Direct 조건 A보다 좋은 응답을 더 많이 생성하는가? |
| RQ2 | 조건 B는 중의적·비격식 표현과 surface-shortcut 사례에서 중대한 의미 오해를 줄이는가? |
| RQ3 | 조건 B는 단순 의미 파악을 넘어 동일한 의미 맥락의 후속 대화와 양립 가능한 응답을 더 많이 생성하는가? |
| RQ4 | 대화 목적 분류의 정확성은 최종 응답의 의미 오류와 대화 연속성에 어떻게 연결되는가? |

### 2.3 사전 등록 가설

| ID | 가설 | 판정 기준 |
|---|---|---|
| H1 | 조건 B의 쌍대 승률이 조건 A보다 높다. | 승패가 결정된 최종 실험 항목의 exact sign/binomial test와 95% CI. 전체 20개 기준 결과 분포도 함께 보고 |
| H2 | 조건 B의 중대한 의미 오해율과 좋은 응답 실패율이 조건 A보다 낮다. | 항목별 대응 결과, exact McNemar test, paired difference와 95% CI |
| H3 | 조건 B의 대화 연속성 점수가 조건 A보다 높다. | 평가자 평균을 이용한 항목별 B−A 차이와 paired bootstrap 95% CI |
| H4 | 조건 B의 개선 폭은 clear보다 ambiguous-informal 및 surface-shortcut에서 크다. | 슬라이스별 효과와 차이의 차이. 탐색 결과로 해석 |

H4는 표본 100개의 파일럿 연구에서는 탐색 가설로 해석한다. 통계적으로 유의하지 않더라도 효과크기, 신뢰구간, 항목별 오류 유형을 함께 보고하며 영가설 수용이나 보편적 무효를 주장하지 않는다.

## 3 이론적 근거와 예상 기여

| 설계 요소 | 학술적 근거 | Pally에서의 적용 |
|---|---|---|
| 대화 목적 중간 표현 | 대화행위는 발화의 의사소통 기능을 모델링하는 단위 | 공통 세 축 예측은 유지하고 B의 응답 생성에만 6종 목적 표현을 추가 |
| 중의적 비격식 슬라이스 | 속어 의미는 문맥과 의미 적합성에 의존 | 단어 자체가 아니라 최소 이전 문맥과 현재 턴 전체에서 의미와 기능 판정 |
| 후속 대화 연속성 | 적절한 응답은 현재 의미를 보존하면서 다음 대화 행동을 가능하게 함 | 평가용 continuation anchor와 probe를 이용해 후속 맥락과의 양립성 평가 |
| 주관 라벨의 명시적 규약 | 주관 과제에서는 합의와 관점 다양성 구분 필요 | v2.2 prescriptive rubric을 고정하고 원시 평가와 불일치 보존 |
| 행동 슬라이스 평가 | 단일 평균은 특정 능력 실패를 가릴 수 있음 | clear, ambiguous-informal, surface-shortcut을 별도 보고 |
| 블라인드 다중 평가 | 응답 평가에는 위치·기대·장황성 편향이 존재 | 연구자 4인 독립 평가, 조건 익명화, 위치 균형, 원시 판정 보존 |

### 3.1 예상 기여

1. **핵심 기여:** 동일한 사용자 발화, 동일한 세 축 예측 및 동일한 응답 생성기를 통제한 상태에서 명시적 대화 목적 intermediate representation을 추가했을 때 발생하는 응답 품질의 증분 효과를 검증한다.
2. **진단적 기여:** 표면 단서 shortcut과 목적 오분류가 의미 보존 및 대화 연속성 오류로 이어지는 사례를 항목별로 제시한다.
3. **대화적 기여:** 슬랭 해석을 단어 의미 분류가 아니라 화자의 태도와 후속 대화 가능성을 보존하는 응답 생성 문제로 평가한다.
4. **실무적 기여:** 100개 소표본에서 학습 자료와 최종 실험 자료를 분리하는 절차, 출력 스키마, 평가 규칙 및 보고 양식을 명세한다.

논문에서는 6종 목적 분류 체계나 목적 분류기 자체를 새로운 핵심 contribution으로 제시하지 않는다. 목적 분류기는 intermediate representation을 생성하기 위한 구현 요소이며, 핵심 contribution은 목적 표현이 없는 조건과 목적 표현이 추가된 조건을 통제 비교해 최종 응답 품질의 증분 효과를 측정하는 데 있다.

## 4 변수와 분석 단위

| 구분 | 정의 | 운영 방식 |
|---|---|---|
| 독립변수 | 응답 생성기의 대화 목적 표현 사용 여부 | A는 목적 미사용, B는 동일한 축 예측에 예측 목적을 추가 |
| 주 종속변수 | 최종 응답의 상대적 적합성과 좋은 응답 여부 | 블라인드 A/B 판정, 사전 정의 통과 기준 |
| 핵심 종속변수 | 의미 오해와 대화 연속성 | 중대한 의미 오해율, 연속성 1–5점 |
| 과정 종속변수 | 목적·3축 측정 정확도 | 목적 macro-F1, 축별 MAE·Spearman |
| 오류 종속변수 | 목적·의미·기능·스타일 손상 | 목적 오분류, 의미 반전, 부적절한 톤, 무관 응답, 대화 단절 |
| 분석 단위 | 하나의 held-out 입력 항목 | 최소 이전 문맥 0–1턴과 현재 사용자 턴. 응답 평가도 항목 단위로 집계 |
| 통제변수 | 모델·특징·학습·생성 조건 | 같은 알고리즘, 특징, train/test split, 생성기, prompt 틀, 길이, decoding |
| 제외 축 | Energy, Intimacy | 음성 및 장기 관계 이력이 없어 0이 아닌 null로 저장 |

### 4.1 항목 구조

각 항목은 다음 요소로 구성한다.

1. `context_before`: 의미 판단에 필요한 이전 문맥 0–1턴
2. `target_turn`: 평가 대상 사용자 턴
3. `intended_slang_sense`: 의도된 문자적 또는 비문자적 의미
4. `speaker_stance`: 긍정, 부정, 중립, 혼합
5. `purpose_primary`: 주 대화 목적
6. `purpose_secondary`: 부 목적 또는 null
7. `required_response_properties`: 좋은 응답이 충족해야 할 속성
8. `forbidden_errors`: 발생하면 안 되는 의미·기능 오류
9. `continuation_anchors`: 이후 대화가 이어질 수 있는 허용 가능한 화제 또는 반응
10. `continuation_probe`: 모델에는 제공하지 않고 평가에만 사용하는 다음 사용자 턴

이전 문맥 없이도 해석 가능한 항목은 `context_before=null`로 둔다. 이전 문맥이 없으면 의미와 목적을 안정적으로 확정할 수 없는 항목은 주 분석에서 제외하거나 `context_insufficient`로 보존한다.

## 5 실험 조건

### 5.1 조건 A Direct

공통 축 회귀기가 문맥과 현재 사용자 턴의 텍스트 특징만으로 Formality·Humor·Curiosity를 예측한다. 응답 생성기는 문맥, 현재 사용자 턴, 세 예측 점수를 입력받는다. 대화 목적 라벨 또는 예측값은 응답 생성기에 제공하지 않는다.

### 5.2 조건 B Purpose-aware

문맥과 현재 사용자 턴에서 6개 중 하나의 대화 목적을 예측한다. 세 축 점수는 조건 A와 동일한 공통 축 회귀기의 예측값을 그대로 사용한다. 응답 생성기는 문맥, 현재 사용자 턴, 예측 목적, 공통 세 축 예측값을 입력받는다.

목적 정보를 응답 생성기에 직접 제공하는 이유는 세 축 숫자만으로 슬랭의 의미와 요구 반응을 충분히 전달할 수 없기 때문이다. 조건 A와 B가 같은 축 예측값을 사용하므로 train–test mismatch가 발생하지 않으며, 응답 품질 차이는 명시적 목적 표현의 추가 여부에 대한 증분 효과로 해석할 수 있다.

### 5.3 실험 범위

시간과 평가 부담을 고려하여 주 실험은 A와 B의 비교에 한정하고 추가 ablation 조건은 후속 연구로 남긴다. 대신 목적 정분류 항목과 오분류 항목을 나누어 B의 응답 성능을 분석하고, 목적 오분류가 의미 보존과 대화 연속성 오류로 이어진 사례를 항목별로 보고한다.

### 5.4 두 조건에서 동일하게 유지하는 요소

- 목적 분류기와 공통 축 회귀기의 알고리즘 및 고정 하이퍼파라미터
- 텍스트 전처리, TF-IDF 특징 범위 및 최대 특징 수
- 고정된 학습 80개와 최종 실험 20개
- 동일한 세 축 예측값, 점수 범위 및 반올림 규칙
- 응답 생성 모델, 버전, 시스템 프롬프트 기본 틀
- temperature, top-p, 최대 길이, stop 조건 및 출력 언어
- 응답 길이 상한과 금지 규칙
- 연구자 평가 rubric과 집계 규칙

조건 B의 목적 필드를 제외한 응답 생성 프롬프트 구조와 지시문은 A와 동일하게 유지한다. 조건별 입력 토큰 수와 응답 길이는 함께 기록한다.

## 6 대화 목적 범주

표본 100개와 단순 ML의 안정성을 고려하여 목적 범주를 10개에서 6개로 통합한다. 목적은 발화의 표면 형태보다 상대에게 요구하는 주 반응을 기준으로 판정한다.

| 코드 | 한국어명 | 판정 질문 | 바람직한 응답 방향 |
|---|---|---|---|
| `answer_inform` | 사실·뜻 답변 요구 | 비교적 한정된 사실, 뜻 또는 정보를 요구하는가? | 정확하고 직접적인 정보 제공 |
| `explain_explore` | 설명·탐색 요구 | 이유, 원리, 비교, 해석 또는 가능성을 넓혀 묻는가? | 설명, 근거, 관점 확장 |
| `act_request` | 행동·요청 | 작성, 추천, 수정, 실행 또는 구체적 행동을 요구하는가? | 요청 수행 또는 실행 가능성 안내 |
| `confirm_repair` | 확인·명료화·수정 | 이해 확인, 선택 확인, 오해 수정 또는 재설명을 요구하는가? | 확인, 정정, 명료화 |
| `acknowledge_empathize` | 공유·평가·감정 반응 | 경험, 상태, 감정 또는 평가에 대한 이해와 반응을 기대하는가? | 인정, 공감, 관련 반응 |
| `social_reciprocate` | 사회적 화답·관계 유지 | 인사, 감사, 칭찬, 감탄 등 관계적 화답과 대화 지속이 중심인가? | 자연스러운 화답과 관계적 연결 |

### 6.1 범주 경계 규칙

- 사실이나 단어의 뜻을 묻고 답의 범위가 좁으면 `answer_inform`을 선택한다.
- 이유, 해석, 비교 또는 다양한 가능성을 요구하면 `explain_explore`를 선택한다.
- 행동 수행이 핵심이면 문장 형식이 질문이어도 `act_request`를 선택한다.
- 기존 이해를 확인하거나 오해를 고치는 것이 핵심이면 `confirm_repair`를 선택한다.
- 경험·감정·평가 내용에 대한 이해와 공감이 핵심이면 `acknowledge_empathize`를 선택한다.
- 인사·감사·칭찬·감탄에 대한 관계적 화답이 핵심이면 `social_reciprocate`를 선택한다.

`joke`, `humorous`, `playful`은 목적 범주로 만들지 않는다. Humor 정답을 목적 단계에서 미리 포함하는 순환 판단을 막기 위해서이다. 복합 목적이 있으면 상대에게 가장 중요한 반응 하나를 `purpose_primary`로 선택하고, 두 번째 목적은 `purpose_secondary`에 저장한다. 평가자 4인 중 2인 이상이 서로 다른 목적을 선택한 항목은 `purpose_ambiguous=true`로 표시한다.

## 7 세 축과 응답 정책

### 7.1 세 축 정의

| 축 | 본 실험의 정의 | 금지되는 shortcut |
|---|---|---|
| Formality | 현재 발화의 구어적 존중, 체면 고려, 직접성 완화 및 register | `please`, 문장 길이, 문법 정확성만으로 상승시키지 않음 |
| Humor | 현재 발화에서 지각되는 유희적 프레이밍, 비문자성, 불일치 및 검수된 밈·슬랭의 유희적 사용 | 슬랭 출현이나 문법 오류만으로 상승시키지 않음 |
| Curiosity | 현재 발화가 정보, 설명, 관점 또는 가능성을 얼마나 명시적으로 요구하는지 | 물음표나 질문형만으로 높은 점수를 부여하지 않음 |

세 축은 각각 0–100점이며 v2.2의 구성요소 가중치와 5점 단위 반올림을 유지한다. 세 축을 하나의 합산 점수로 만들지 않는다. Energy와 Intimacy는 0이 아니라 null로 저장한다.

### 7.2 좋은 응답의 정의

본 연구에서 좋은 응답은 다음 조건을 모두 충족하는 응답이다.

1. 슬랭의 문자적·비문자적 의미와 화자의 태도를 정확히 보존한다.
2. 현재 발화가 요구하는 핵심 반응을 수행한다.
3. 사용자 스타일과 조화를 이루되 공격성, 과도한 친밀감, 부적절한 농담을 그대로 모방하지 않는다.
4. 동일한 의미 맥락에서 이어질 수 있는 구체적인 반응 또는 후속 화제를 제공한다.
5. 간결하고 자연스러우며 새로운 사실을 근거 없이 만들어내지 않는다.

### 7.3 목적별 응답 정책

| 목적 | 필수 반응 | 대화 연속성의 예 | 피해야 할 반응 |
|---|---|---|---|
| `answer_inform` | 먼저 정확한 답을 제공 | 관련 예시, 적용 범위 또는 선택 가능한 추가 설명 | 답을 미루고 질문만 되돌림 |
| `explain_explore` | 이유와 구조를 설명 | 관련 비교, 관점 또는 다음 탐색 질문 제안 | 단답 또는 근거 없는 단정 |
| `act_request` | 가능한 범위에서 요청 수행 | 다음 단계, 선택지 또는 필요한 입력 안내 | 사용자가 요구하지 않은 장황한 설명 |
| `confirm_repair` | 이해를 확인하거나 오류를 수정 | 수정된 이해를 바탕으로 다음 행동 제안 | 잘못된 전제를 그대로 강화 |
| `acknowledge_empathize` | 경험·감정·평가를 인정 | 공유된 내용과 직접 관련된 반응 또는 구체적 후속 질문 | 감정을 축소하거나 즉시 화제 전환 |
| `social_reciprocate` | 인사·감사·칭찬에 자연스럽게 화답 | 관계적 맥락에 맞는 짧고 구체적인 연결 | 문자적 오해, 과도한 자기과시, 부적절한 친밀감 |

### 7.4 축별 스타일 적용 원칙

- **Formality:** 사용자의 격식 수준과 크게 충돌하지 않는 범위에서 응답하되 무례함이나 공격성을 모방하지 않는다.
- **Humor:** 발화가 실제로 유희적이고 안전한 경우에만 가벼운 유머를 사용할 수 있다. 고통, 위험, 혐오 또는 진지한 도움 요청에서는 슬랭이 있어도 유머를 우선하지 않는다.
- **Curiosity:** 질문이나 탐색 요구에는 먼저 핵심 답을 제공한 뒤 필요한 경우 관련 확장을 제시한다. 모든 응답 끝에 기계적으로 질문을 붙이지 않는다.
- **목적 우선:** 목적 충족과 의미 보존이 스타일 모방보다 우선한다.
- **안전 우선:** 위험하거나 민감한 상황에서는 스타일 일치보다 안전하고 명확한 대응을 우선한다.

## 8 데이터 구성과 표본 정의

### 8.1 총 표본

총 100개 항목을 사용한다. 이 중 80개는 학습 자료, 20개는 최종 실험 자료로 한 번만 분리한다. 최종 실험 20개의 텍스트와 라벨은 모델·특징·하이퍼파라미터·프롬프트 및 평가 기준을 확정할 때 사용하지 않는다.

| 슬라이스 | N | 포함 기준 |
|---|---:|---|
| clear | 30 | 의미와 요구 반응이 표면적으로 명확한 발화 |
| ambiguous-informal | 40 | 문자적·비문자적 해석 또는 복수 기능이 가능한 중의적 슬랭·비격식 표현 |
| surface-shortcut | 30 | 물음표, `please`, 슬랭 출현 등 단일 표면 단서가 잘못된 목적·축 판단을 유도할 수 있는 발화 |
| 합계 | 100 | 세 슬라이스는 주 분석에서 상호 배타적 |

위 비율은 실제 사용자 발화의 자연 분포를 추정한 것이 아니라 행동적 스트레스 테스트를 위한 설계 비율이다.

학습 자료와 최종 실험 자료의 슬라이스 구성은 다음과 같이 고정한다.

| 슬라이스 | 학습 | 최종 실험 | 합계 |
|---|---:|---:|---:|
| clear | 24 | 6 | 30 |
| ambiguous-informal | 32 | 8 | 40 |
| surface-shortcut | 24 | 6 | 30 |
| 합계 | 80 | 20 | 100 |

최종 실험 20개는 서로 다른 lexical family에서 하나씩 선정한다. 목적 6종은 최종 실험에 각 3–4개가 포함되도록 하고, 의미 유형과 화자 태도가 한쪽에 몰리지 않도록 한다.

### 8.2 목적 분포

6개 목적 범주는 각각 약 16–17개가 되도록 구성한다. 각 목적이 특정 슬라이스에만 포함되지 않도록 가능한 범위에서 목적과 슬라이스를 교차 배치한다. 정확한 목적·슬라이스 교차표는 모델 학습 전에 고정하고 논문에 공개한다.

### 8.3 lexical family와 중복 방지

동일 핵심 표현, 동일 템플릿, 단순 대명사·시제 변형 및 같은 수집 세션에서 나온 항목은 하나의 `lexical_family_id`로 묶는다.

- 한 lexical family에는 최대 2개 항목만 포함한다.
- 같은 family의 항목은 반드시 학습 또는 최종 실험 중 한쪽에만 배정한다.
- 특정 슬랭 하나가 ambiguous-informal 항목의 20%를 초과하지 않게 한다.
- near-duplicate와 정확 중복은 학습 전에 제거한다.
- 같은 화자 또는 같은 수집 세션을 식별할 수 있으면 같은 그룹으로 묶는다.

### 8.4 권장 데이터 필드

| 필드군 | 필드 | 역할 |
|---|---|---|
| 식별·그룹 | `item_id`, `lexical_family_id`, `source_id` | 중복 방지와 grouped split |
| 입력 | `context_before`, `target_turn`, `language_form` | 모델에 제공하는 최소 문맥과 현재 턴 |
| 의미 | `intended_slang_sense`, `literal_or_nonliteral`, `speaker_stance` | 의미 및 태도 정답 |
| 목적 | `purpose_primary`, `purpose_secondary`, `purpose_ambiguous` | 6종 목적과 모호성 |
| 축 | `formality`, `humor`, `curiosity`, `energy=null`, `intimacy=null` | v2.2 인간 정답 |
| 상태 | `case_type`, `score_status`, `confidence` | 슬라이스와 확정 상태 |
| 근거 | `axis_rationale`, `purpose_rationale`, `sense_rationale` | 감사 가능한 짧은 근거 |
| 응답 명세 | `reference_response`, `required_properties`, `forbidden_errors` | 표현 다양성을 허용하는 정답 기준 |
| 연속성 | `continuation_anchors`, `continuation_probe` | 후속 맥락과의 양립성 평가 |
| 출처 | `label_source`, `annotator_id_hash`, `rubric_version` | human/pseudo 구분과 추적 |
| 분할 | `split` | `train` 또는 `final_test` |

## 9 인간 라벨 생성

### 9.1 라벨링 절차

연구자 4인은 모델 출력 생성 전에 100개 항목을 독립적으로 평가한다. 각 연구자는 출처, 다른 평가자의 라벨, 모델 예측 및 연구 조건을 보지 않는다.

각 항목에 대해 다음을 기록한다.

- `intended_slang_sense`와 `speaker_stance`
- `purpose_primary`와 필요한 경우 `purpose_secondary`
- Formality·Humor·Curiosity 점수
- `case_type`, `confidence`, 짧은 판정 근거
- `required_properties`, `forbidden_errors`
- 허용 가능한 `continuation_anchors`와 평가용 `continuation_probe`

### 9.2 합의 라벨 생성

- 목적 범주는 4인 중 3인 이상의 일치를 우선 합의로 사용한다.
- 2대 2 또는 3인 이상 일치가 없는 경우 원시 판정을 보존한 뒤 근거를 검토해 합의본을 만든다.
- 세 축 점수는 4인 중앙값을 합의 점수로 사용하고 5점 단위로 유지한다.
- 의미와 태도는 3인 이상의 일치를 우선 사용한다.
- 합의 과정은 최초 독립 판정을 덮어쓰지 않고 별도 필드에 저장한다.
- 합의가 어려운 항목은 `boundary` 또는 `context_insufficient`로 표시한다.

`context_insufficient` 항목은 주 응답 평가와 축 회귀에서 제외하고 진단용으로 보존한다. 제외로 인해 총 100개가 되지 않으면 모델 실행 전에 동일한 절차로 대체 항목을 추가한다.

### 9.3 라벨 신뢰도

- 목적과 의미 범주: 단순 일치율 및 Krippendorff’s alpha 또는 Fleiss’ kappa
- 축 점수: 평가자 간 MAE, Spearman 상관 및 ICC
- continuation anchor 작성: 핵심 화제 또는 반응 단위의 일치율

라벨 작성 단계에서는 LLM 제안을 연구자에게 노출하지 않는다. 연구자가 평가하는 대상은 개인의 성향이 아니라 발화와 모델 응답이며, 원시 라벨과 합의 라벨을 모두 보존한다.

## 10 학습 80개와 최종 실험 20개

### 10.1 자료 분할

100개 항목을 학습 자료 80개와 최종 실험 자료 20개로 한 번만 나눈다. 목적 분류기와 공통 축 회귀기는 동일한 80개만 사용해 학습한다. 최종 실험 20개는 두 모델 모두 처음 보는 자료이며, 이 20개에서 생성한 A/B 응답만 주 결과에 사용한다.

```text
전체 100개
├─ 학습 80개: 목적 분류기와 공통 축 회귀기 학습
└─ 최종 실험 20개: 목적·축 예측과 A/B 응답 생성 및 평가
```

분할은 목적, 슬라이스, 의미 유형의 분포를 고려하여 사전에 고정한다. 같은 lexical family는 학습과 최종 실험에 동시에 포함하지 않는다. 최종 실험 20개는 모델 설정, 특징 선택, 프롬프트 수정 및 평가 기준 조정에 사용하지 않는다.

### 10.2 고정 모델

복잡한 모델 탐색에 따른 과적합을 줄이기 위해 다음 단순 ML 구성을 사전에 고정한다.

#### 목적 분류기

- 특징: word TF-IDF 1–2gram과 character TF-IDF 3–5gram의 결합
- 모델: Logistic Regression
- class weight: balanced
- 기본 규제 강도: `C=1.0`
- 최대 반복: `max_iter=2000`
- 목적 출력: 6개 범주의 확률과 최고 확률 범주

#### 공통 세 축 회귀기

- 특징: 목적 분류기와 동일한 텍스트 TF-IDF 특징
- 모델: 축별 Ridge Regression 3개
- 기본 규제 강도: `alpha=1.0`
- 출력: 0–100 범위로 제한한 뒤 5점 단위 반올림

공통 축 회귀기는 목적 라벨이나 목적 예측값을 입력으로 사용하지 않는다. 최종 실험 항목에서 생성한 세 축 예측값 하나를 조건 A와 B가 그대로 공유한다.

모델과 하이퍼파라미터는 최종 실험 20개의 결과를 확인하기 전에 고정한다. 최종 결과를 확인한 뒤 설정을 바꾸면 기존 20개를 다시 최종 실험 자료로 사용할 수 없으므로, 변경 사항은 후속 연구로 남긴다.

### 10.3 누출 방지

- TF-IDF 어휘와 IDF 값은 학습 80개에서만 계산한다.
- 목적 분류기와 공통 축 회귀기의 학습에는 최종 실험 20개의 텍스트 또는 라벨을 사용하지 않는다.
- 공통 축 회귀기는 학습과 최종 실험 모두에서 목적 정보를 입력으로 사용하지 않는다.
- 전처리, 특징 선택 및 스케일링도 학습 80개에서만 적합한다.
- 80/20 분할표는 모델 학습 전에 고정하고 공개한다.
- 최종 실험 결과를 본 뒤 목적 범주, 하이퍼파라미터, 프롬프트 또는 채점 기준을 수정하지 않는다.

### 10.4 응답 생성

최종 실험 20개의 목적과 축을 예측하고 각 항목에서 A와 B 응답을 하나씩 생성한다. 각 항목의 A와 B에는 완전히 동일한 세 축 예측값을 제공하고, B에만 예측 목적을 추가한다. 이에 따라 연구자 평가 대상은 A/B 응답 쌍 20개, 개별 응답 40개이다. 응답 생성기는 두 조건에서 동일한 모델과 버전을 사용한다.

- temperature는 가능하면 0으로 고정한다.
- 비결정적 API를 사용하면 생성 seed 또는 요청 ID를 기록한다.
- 최대 응답 길이와 출력 언어를 동일하게 유지한다.
- 실제 이전 대화 전체가 아니라 `context_before`와 `target_turn`만 제공한다.
- `continuation_probe`는 모델에 제공하지 않는다.
- 조건 B만 `predicted_purpose` 필드를 추가한다. 그 밖의 입력 필드와 값은 동일하다.

## 11 구현 절차

1. Rubric v2.2, 목적 6종, 좋은 응답 기준, 제외 기준, 80/20 분할, 모델 설정 및 평가 양식을 사전 고정한다.
2. 연구자 4인이 인간 정답, 응답 명세 및 연속성 기준을 독립적으로 작성한다.
3. 원시 라벨의 일치도와 비정상적인 exact agreement를 확인하고 합의 라벨을 생성한다.
4. lexical family 단위로 학습 80개와 최종 실험 20개를 분리한다.
5. 학습 80개로 목적 분류기와 공통 축 회귀기를 각각 한 번 학습한다.
6. A와 B가 동일한 축 예측값을 사용하고 B의 목적 예측값은 응답 생성기에만 추가되는지 payload와 로그로 확인한다.
7. 최종 실험 20개에서 같은 생성 조건으로 A/B 응답 20쌍을 생성한다.
8. 모든 응답을 X/Y로 익명화하고 연구자 4인에게 평가자별 무작위 순서로 제시한다.
9. 연구자 4인은 서로 협의하지 않고 의미, 목적, 스타일, 연속성, 자연스러움을 평가한다.
10. 항목 단위로 승패·동률·둘 다 부적합·판정 불일치를 집계한다.
11. 목적 정·오분류→응답 오류 연결표와 대표 사례를 작성한다.
12. 결과 확인 후 rubric이나 임계값을 수정하지 않는다. 수정이 필요하면 새 학습·시험 자료로 후속 실험을 설계한다.

## 12 최종 응답 평가

### 12.1 평가자와 블라인드 절차

주 평가자는 연구자 4인이다. 네 평가자는 최종 실험 20개의 A/B 응답 쌍을 모두 독립적으로 평가한다.

- 조건 A와 B의 명칭을 공개하지 않는다.
- 목적 예측값, 축 점수와 모델 내부 정보를 공개하지 않는다.
- 두 응답을 X와 Y로 익명화한다.
- 평가자와 항목마다 X/Y 순서를 무작위화한다.
- 전체적으로 A와 B가 X 위치에 나타나는 횟수를 가능한 한 균형 있게 맞춘다.
- 같은 평가자에게 동일 응답 쌍을 역순으로 다시 제시하지 않는다.
- 평가 중 연구자끼리 협의하지 않는다.
- 최초 독립 평가를 저장한 뒤에만 불일치 사례를 검토한다.

평가자에게는 `context_before`, `target_turn`, 인간 합의 의미, 응답의 required properties, forbidden errors, continuation anchor와 필요한 경우 continuation probe를 제공한다. reference response는 특정 문장 복제를 유도할 수 있으므로 주 평가 화면에서는 제공하지 않고 사후 오류 검토에만 사용한다.

### 12.2 평가 순서

각 평가자는 응답 X와 Y를 다음 순서로 평가한다.

1. 중대한 의미 오류 여부를 판정한다.
2. 의미·태도 보존, 목적 충족, 스타일 적절성, 대화 연속성, 자연스러움을 각각 1–5점으로 평가한다.
3. 사전 정의된 좋은 응답 통과 기준을 적용한다.
4. 점수와 통과 여부에 따라 X 승, Y 승, 동률, 둘 다 부적합 중 하나를 기록한다.
5. 판정 근거가 되는 짧은 증거를 기록한다.

## 13 좋은 응답 채점 기준

### 13.1 중대한 오류

다음 중 하나라도 발생하면 `critical_error=true`로 판정한다.

- 문자적 의미와 비문자적 의미를 반대로 해석함
- 칭찬·호의와 비난·적의를 반대로 해석함
- 사용자의 핵심 요청과 반대되는 행동을 수행함
- 입력에 없는 사실을 만들어 의미를 왜곡함
- 안전·민감 상황에서 부적절한 농담이나 위험한 조언을 제공함
- 현재 문맥과 양립할 수 없는 화제 또는 전제를 응답의 핵심으로 삼음

단순한 문체 어색함이나 짧은 응답은 그 자체로 중대한 오류가 아니다.

### 13.2 차원별 1–5점 rubric

#### 의미와 태도 보존

| 점수 | 기준 |
|---:|---|
| 1 | 슬랭의 핵심 의미 또는 화자의 긍정·부정 태도를 반대로 해석한다. |
| 2 | 일부 관련 의미를 인식하지만 핵심 의미나 태도를 크게 왜곡한다. |
| 3 | 주요 의미는 대체로 맞지만 중의성 또는 화자 태도의 일부가 불명확하다. |
| 4 | 문자적·비문자적 의미와 화자 태도를 정확히 보존하며 사소한 누락만 있다. |
| 5 | 의미, 태도, 문맥상 함의를 정확히 보존하고 응답 전체에 일관되게 반영한다. |

#### 대화 목적 충족

| 점수 | 기준 |
|---:|---|
| 1 | 요구된 반응 유형을 놓치거나 반대로 응답한다. |
| 2 | 목적과 일부 관련되지만 핵심 요구를 거의 수행하지 못한다. |
| 3 | 핵심 목적에 대체로 반응하지만 내용이 약하거나 부분적으로만 충족한다. |
| 4 | 핵심 목적을 정확히 수행하며 필요한 정보 또는 반응을 제공한다. |
| 5 | 핵심 목적을 정확히 수행하고 문맥에 맞는 우선순위와 깊이로 반응한다. |

#### 스타일 적절성

| 점수 | 기준 |
|---:|---|
| 1 | 격식·유머·탐색 방식이 상황과 명백히 충돌하거나 부적절하다. |
| 2 | 일부 스타일 요소는 맞지만 과도한 모방, 경직성 또는 부적절한 농담이 두드러진다. |
| 3 | 전반적으로 수용 가능하지만 세 축 반영이 약하거나 일관성이 부족하다. |
| 4 | 목적과 문맥에 적절한 격식·유머·탐색 수준을 안정적으로 유지한다. |
| 5 | 사용자 스타일과 조화를 이루면서도 안전성과 역할 경계를 지키고 자연스럽게 조절한다. |

#### 대화 연속성

| 점수 | 기준 |
|---:|---|
| 1 | 의미를 잘못 이해하거나 화제를 단절·전환하여 후속 대화와 연결되지 않는다. |
| 2 | 표면적으로 관련되지만 다음 대화를 이어갈 실질적인 연결이 거의 없다. |
| 3 | 무난하게 반응하며 일반적인 후속 대화는 가능하지만 연결 단서가 모호하거나 상투적이다. |
| 4 | 현재 의미와 직접 관련된 구체적인 반응, 정보 또는 후속 화제를 제공한다. |
| 5 | 의미·태도·목적을 보존하면서 continuation anchor 또는 probe와 매우 자연스럽게 이어지는 구체적인 대화 경로를 연다. |

질문을 덧붙였다는 이유만으로 높은 점수를 주지 않는다. 먼저 필요한 반응을 수행한 뒤 의미에 기반한 구체적인 연결을 제공해야 한다. 질문 없이도 충분한 인정, 설명 또는 관련 정보로 다음 대화를 가능하게 하면 높은 점수를 받을 수 있다.

#### 관련성과 자연스러움

| 점수 | 기준 |
|---:|---|
| 1 | 무관하거나 이해하기 어렵고 실제 대화를 지속하기 어렵다. |
| 2 | 일부 관련되지만 매우 어색하거나 반복적·장황하다. |
| 3 | 이해 가능하고 대체로 관련되지만 다소 기계적이거나 불필요한 내용이 있다. |
| 4 | 간결하고 자연스러우며 문맥에 직접 관련된다. |
| 5 | 불필요한 내용 없이 자연스럽고 구체적이며 실제 대화에 바로 사용할 수 있다. |

### 13.3 좋은 응답 통과 기준

한 평가자 기준으로 다음을 모두 충족하면 `good_response=true`로 판정한다.

- `critical_error=false`
- 의미와 태도 보존 4점 이상
- 대화 목적 충족 3점 이상
- 스타일 적절성 3점 이상
- 대화 연속성 3점 이상
- 관련성과 자연스러움 3점 이상

### 13.4 평가자별 쌍대 판정 규칙

각 평가자는 다음 규칙으로 X/Y 판정을 기록한다.

1. 한 응답만 좋은 응답 기준을 통과하면 통과한 응답이 승리한다.
2. 두 응답 모두 통과하지 못하면 `both_bad`로 판정한다.
3. 두 응답 모두 통과하고 5개 점수 합계 차이가 3점 이상이면 높은 응답이 승리한다.
4. 두 응답 모두 통과하고 점수 합계 차이가 2점 이하이면 `tie`로 판정한다.
5. 규칙과 전문적 판단이 충돌한다고 느끼면 규칙에 따른 결과를 기록하고 근거란에 충돌 이유를 남긴다.

### 13.5 연구자 4인 집계 규칙

- 3명 이상이 X 승을 선택하면 X 승
- 3명 이상이 Y 승을 선택하면 Y 승
- 3명 이상이 동률을 선택하면 동률
- 3명 이상이 둘 다 부적합을 선택하면 둘 다 부적합
- 어느 범주도 3표를 얻지 못하면 `no_consensus`로 기록

`no_consensus`를 사후 협의로 강제 승패 처리하지 않는다. 주 결과 분포에 포함하고, 승패만 사용하는 sign test에서는 제외하되 제외 수를 명시한다.

| 지표 | 산출 방식 | 선정 이유 |
|---|---|---|
| 블라인드 쌍대 결과 | B 승, A 승, 동률, 둘 다 부적합, no-consensus의 항목 수와 비율 | 상대 승률이 공통 실패와 판정 불안을 숨기지 않게 함 |
| 조건부 B 승률 | A 또는 B 승으로 결정된 항목 중 B 승 비율 | 방향성 있는 비교에 대한 H1 검정 |
| 좋은 응답 통과율 | 평가자 4인 중 3인 이상이 good로 판정한 항목 비율 | 절대 품질을 함께 평가 |

### 14.2 핵심 결과

| 지표 | 산출 방식 | 해석 |
|---|---|---|
| 중대한 의미 오해율 | 평가자 4인 중 3인 이상이 critical error로 판정한 항목 비율 | 슬랭 의미와 태도의 실질적 손상 |
| 대화 연속성 | 4인 점수 평균의 항목별 B−A 차이 | 후속 맥락과 양립 가능한 응답 개선 |
| 목적 충족 | 4인 점수 평균의 항목별 B−A 차이 | 목적 표현이 요구 반응 수행에 미치는 영향 |
| both-bad 비율 | 두 응답 모두 좋은 응답 기준을 통과하지 못한 항목 비율 | 공통 생성 실패 확인 |

### 14.3 과정 및 진단 지표

| 단계 | 지표 | 해석 |
|---|---|---|
| 대화 목적 | macro-F1, 범주별 precision·recall·F1, confusion matrix | 6개 목적의 불균형과 혼동 확인 |
| 세 축 | 축별 MAE, Spearman ρ | 절대 점수 오차와 순위 일치 분리 |
| 오류 전파 | 목적 정·오분류별 응답 오류율 | 목적 오류가 의미 보존과 대화 연속성 손상으로 이어지는지 진단 |
| 평가자 신뢰도 | 범주 일치도, ICC, no-consensus 비율 | 주 평가의 안정성 확인 |
| 생성 특성 | 응답 길이, 입력 토큰, 지연시간 | 장황성 및 목적 조건의 실무 비용 확인 |

## 15 통계 분석 계획

통계 단위는 평가자 표가 아니라 최종 실험 20개의 입력 항목이다. 평가자 4인의 표를 80개의 독립 표본으로 계산하지 않는다.

1. 각 항목에서 B 승, A 승, 동률, 둘 다 부적합 또는 no-consensus를 확정한다.
2. H1은 A 또는 B 승으로 결정된 항목에 exact sign/binomial test를 적용하고 조건부 B 승률의 95% Wilson CI를 보고한다.
3. 전체 20개를 분모로 B 승 비율, A 승 비율, 동률, both-bad, no-consensus를 함께 제시한다.
4. H2의 중대한 의미 오해와 좋은 응답 통과 여부는 대응된 이진 결과이므로 discordant pair 수와 exact McNemar test를 보고한다.
5. H3의 대화 연속성은 평가자 4인 평균을 이용해 항목별 B−A 차이를 계산한다. 평균, 중앙값 및 item-level paired bootstrap 95% CI를 보고한다.
6. 나머지 1–5점 하위 점수도 같은 방식으로 항목별 paired difference와 bootstrap CI를 보고한다.
7. H4는 clear 6개, ambiguous-informal 8개, surface-shortcut 6개의 B−A 효과를 기술적으로 제시한다. 각 슬라이스가 매우 작으므로 유의성 검정보다 개별 사례와 효과 방향을 보고한다.

8. 목적 분류가 틀린 B 항목은 별도로 모아 목적 오류→의미·연속성 오류 연결표를 작성한다. 이는 인과효과 확정이 아니라 오류 경로 진단이다.
9. 목적 범주형 평가의 신뢰도는 단순 일치율과 Krippendorff’s alpha 또는 Fleiss’ kappa를 보고한다.
10. 1–5점 응답 평가는 ICC를 보고한다. ICC 유형과 단일 평가자 또는 평균 평가 기준을 논문에 명시한다.
11. 최종 실험이 20개이므로 통계 검정은 큰 효과만 탐지할 수 있다. p-value보다 효과크기, 신뢰구간 및 대표 실패 사례를 우선하고 모든 결과를 파일럿으로 해석한다.

## 18 연구윤리와 데이터 처리

본 연구는 신규 외부 참여자를 모집하지 않고 연구팀 내 평가자 4인이 익명화된 모델 응답을 사전에 정의한 기준에 따라 독립적으로 평가하도록 설계한다. 평가 대상은 연구자의 개인적 특성이 아니라 모델 출력이다.

다만 연구팀 평가라는 사실만으로 인간대상연구 비해당 또는 IRB 심의면제가 자동으로 성립하는 것은 아니다. 다음을 별도로 확인한다.

- 실제 사용자 발화 또는 개인식별정보 포함 여부
- 기존 인간 자료의 동의 범위와 수집 목적
- 공개 또는 비식별 자료의 재식별 가능성
- 외부 학생 또는 일반인의 추가 평가 참여 여부
- 평가자의 개인적 특성이나 행동을 연구 자료로 분석하는지 여부

기관 확인 전에는 논문에서 IRB가 필요 없다고 단정하지 않는다. 입력 자료의 출처, 이용 조건, 비식별화 방법과 보존 기간을 기록하고 소속 기관의 연구윤리 절차를 따른다.

## 22 논문 Methods 초안

본 연구는 중의적·비격식 사용자 발화에서 의사소통 목적을 명시적 중간 표현으로 사용하는 purpose-aware 경로의 효과를 검증하였다. 분석 자료는 최소 이전 문맥 0–1턴과 현재 사용자 턴으로 구성된 100개 항목이며, clear 30개, ambiguous-informal 40개, surface-shortcut 30개로 구성하였다. 동일 핵심 표현과 문장 변형은 lexical family로 묶고 학습 자료와 최종 실험 자료에 동시에 포함하지 않았다.

100개 항목 중 80개를 학습 자료로, 20개를 최종 실험 자료로 사전 분리하였다. 최종 실험 자료는 clear 6개, ambiguous-informal 8개, surface-shortcut 6개로 구성하였다. 목적 분류에는 word 및 character TF-IDF와 Logistic Regression을 사용하였고, Formality·Humor·Curiosity 추정에는 축별 Ridge Regression을 사용하였다. 모든 특징과 모델은 학습 80개에만 적합하였으며 최종 실험 20개의 텍스트와 라벨은 모델 또는 평가 기준 수정에 사용하지 않았다.

Direct 조건과 Purpose-aware 조건은 문맥과 현재 사용자 턴의 텍스트 특징에서 공통 축 회귀기가 예측한 동일한 Formality·Humor·Curiosity 값을 사용하였다. Direct 응답 생성기는 문맥, 현재 사용자 턴 및 세 축을 입력받았다. Purpose-aware 조건은 6개 범주 중 하나의 대화 목적을 추가로 예측하고, 동일한 입력에 예측 목적만 추가하여 응답을 생성하였다. 두 조건은 동일한 80/20 분할, 축 예측값, 응답 생성 모델, 길이 제한 및 decoding 설정을 사용하였다. 따라서 조건 간 차이는 명시적 대화 목적 intermediate representation의 제공 여부였다.

최종 응답은 조건명과 중간 예측을 숨긴 상태에서 연구자 4인이 독립적으로 평가하였다. 평가자는 의미와 태도 보존, 대화 목적 충족, 스타일 적절성, 대화 연속성, 관련성과 자연스러움을 각각 1–5점으로 판정하고 중대한 의미 오류 여부를 기록하였다. 좋은 응답은 중대한 오류가 없고, 의미와 태도 보존이 4점 이상이며, 나머지 네 항목이 각각 3점 이상인 응답으로 정의하였다. 주 결과는 항목별 A/B 쌍대 결과와 좋은 응답 통과율이었으며, 중대한 의미 오해율과 대화 연속성 점수를 핵심 결과로 사용하였다.

통계 단위는 평가자 표가 아니라 최종 실험 20개 항목이었다. 승패가 결정된 항목에는 exact sign test를 적용하였고, 중대한 의미 오류와 좋은 응답 통과 여부에는 exact McNemar test를 사용하였다. 1–5점 하위 점수는 항목별 B−A 차이와 paired bootstrap 95% 신뢰구간을 보고하였다. 목적 macro-F1과 공통 축 회귀기의 MAE·Spearman 상관을 과정 지표로 사용하고, 목적 정분류와 오분류에 따른 응답 오류 사례를 별도로 분석하였다. 작은 최종 실험 표본을 고려하여 모든 결과를 파일럿으로 해석하였다.

## 23 해석 범위

- 본 연구는 대화 목적을 포함한 purpose-aware 경로의 응답 적합성과 후속 맥락 양립성을 평가한다.
- 결과가 좋아도 실제 사용자가 더 오래 대화하거나 더 만족한다고 직접 결론내리지 않는다.
- continuation probe는 실제 사용자 행동이 아니라 연구자가 사전 정의한 후속 맥락 기준이다.
- 표본은 실제 사용 분포가 아니라 중의성과 shortcut 실패를 강조한 행동적 테스트 자료이다.
- N=100과 단순 ML 결과는 파일럿으로 보고하며 목적 범주, 언어, 세대, 문화 및 사용자 집단 전체로 일반화하지 않는다.
- B가 우수하더라도 목적 표현 자체의 보편적 우월성이 아니라 본 데이터·모델·생성 조건에서의 증분 효과로 해석한다.
- 연구자 4인이 가설을 알고 있다는 점에서 기대 편향을 완전히 제거할 수 없으며, 후속 연구에서는 외부 인간 평가와 untouched test를 추가할 필요가 있다.
